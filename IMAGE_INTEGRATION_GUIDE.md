## 🔧 **STEP 4: Image Specifications**

### **Apple Watch Screenshots:**
- **Size**: 368x448 pixels (Apple Watch aspect ratio)
- **Format**: PNG with transparency preferred
- **Quality**: High resolution for crisp display

### **Testimonial Photos:**
- **Size**: 300x300 pixels minimum
- **Format**: JPG optimized for web
- **Style**: Professional headshots, good lighting

### **Lifestyle Photos:**
- **Size**: 1200x800 pixels minimum
- **Format**: JPG optimized for web
- **Style**: Warm, family-oriented, authentic moments

### **Brand Assets:**
- **Logo**: SVG preferred, PNG as backup
- **Size**: Vector or 1000px width minimum
- **Variants**: Both light and dark versions

### **If Images Don't Appear:**
- ✅ Check file names match exactly (case-sensitive)
- ✅ Ensure Images folder is in `public/Images/`
- ✅ Refresh browser cache (Ctrl+F5 or Cmd+Shift+R)
- ✅ Check browser console for any errors

---

## 💡 **STEP 6: Image Optimization Tips**

### **For Best Performance:**
1. **Compress images** before copying (keep under 500KB each)
2. **Use modern formats** (WebP if possible, JPG as backup)
3. **Optimize for web** (sRGB color space, appropriate resolution)

### **For Apple Watch Screenshots:**
1. **Take actual screenshots** from DOZY app on Apple Watch
2. **Crop to watch screen** only (remove watch frame)
3. **Ensure text is readable** at small sizes
